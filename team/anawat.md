Pragmatic Promise : สัปดาห์นี้ผมจะพยายามทำความเข้าใจเรื่อง Git และการทำงานร่วมกันในทีมให้มากขึ้น โดยจะฝึกใช้ Branch, Commit และ Pull Request ให้ถูกต้อง

ทำไมอยากเรียน SE ? : ผมอยากเรียน Software Engineering เพราะอยากรู้ว่าการทำซอฟต์แวร์เป็นทีมจริง ๆ ต้องวางแผนและจัดการงานกันอย่างไร ไม่ใช่แค่เขียนโค้ดให้ใช้งานได้ แต่อยากทำงานให้เป็นระบบและลดปัญหาที่อาจเกิดขึ้นในอนาคต

Broken Window : เคยเจอปัญหาตอนทำงานกลุ่มที่มีโค้ดบางส่วนเขียนไว้แต่ไม่ได้จัดระเบียบหรือแก้ให้เรียบร้อย พอปล่อยไว้นาน ๆ คนอื่นที่มาทำต่อก็ไม่เข้าใจโค้ดและเกิดปัญหาเพิ่มขึ้น ถ้าเจออีกครั้งผมจะรีบแก้และจัดโค้ดให้เรียบร้อยตั้งแต่แรก เพื่อไม่ให้ปัญหาเล็ก ๆ กลายเป็นปัญหาใหญ่ภายหลัง
