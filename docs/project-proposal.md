# Project Proposal: CampusLink

## Theme
**Education & Student Community Support**
เลือกธีมนี้เนื่องจากนักศึกษามหาวิทยาลัยส่วนใหญ่ประสบปัญหาเรื่องการกระจัดกระจายของข้อมูลข่าวสารและการปรับตัวในชีวิตมหาวิทยาลัย การสร้างแพลตฟอร์มศูนย์กลางจะช่วยเชื่อมโยงนักศึกษาเข้าหากิจกรรม กลุ่มเรียน และทรัพยากรต่างๆ ของมหาวิทยาลัยได้อย่างมีประสิทธิภาพ อีกทั้งยังช่วยสร้างสังคมการเรียนรู้และซัพพอร์ตซึ่งกันและกันภายในรั้วมหาวิทยาลัยได้อย่างยั่งยืน

## Project Name
**CampusLink** (แพลตฟอร์มศูนย์กลางข้อมูลข่าวสารและชุมชนนักศึกษามหาวิทยาลัย)

## Persona หลัก
**น้องมินต์ (นักศึกษาชั้นปีที่ 1 คณะเทคโนโลยีสารสนเทศ):** เด็กกิจกรรมรุ่นใหม่ที่เพิ่งเข้ามาเรียนในมหาวิทยาลัย กำลังพยายามปรับตัวกับการเรียนและการใช้ชีวิตในรั้วมหาวิทยาลัย มินต์ต้องการค้นหากลุ่มเพื่อนที่มีความสนใจคล้ายกัน กิจกรรมนอกหลักสูตรเพื่อเก็บชั่วโมงกิจกรรม และแหล่งสรุปชีทเรียนหรือรุ่นพี่คอยให้คำแนะนำ แต่ประสบปัญหาข้อมูลกระจัดกระจายตามกลุ่ม Facebook, LINE OpenChat หรือประกาศของมหาวิทยาลัยที่กระจัดกระจายจนตามไม่ทัน

## Value Proposition
CampusLink ช่วยแก้ปัญหาการกระจัดกระจายของข้อมูลข่าวสารและสังคมในมหาวิทยาลัย โดยรวบรวมประกาศ กิจกรรม คลับ/ชมรม และแหล่งแลกเปลี่ยนความรู้ไว้ในที่เดียว ทำให้ผู้ใช้งาน (นักศึกษา) สามารถเข้าถึงโอกาส การมีส่วนร่วมในกิจกรรม และสร้างเครือข่ายเพื่อน/รุ่นพี่ได้อย่างสะดวกรวดเร็ว ช่วยลดความเครียดในการปรับตัวและเพิ่มประสิทธิภาพชีวิตการเรียนในมหาวิทยาลัย

## MoSCoW priorities
* **Must have:** 
  * ระบบลงทะเบียนและยืนยันตัวตนด้วยอีเมลมหาวิทยาลัย (`@student.ac.th`)
  * หน้าฟีดรวมประกาศข่าวสาร กิจกรรม และอีเวนต์ของมหาวิทยาลัย พร้อมระบบกรองตามคณะ/ความสนใจ
* **Should have:** 
  * ระบบชุมชน/ชมรม (Student Clubs & Groups) ให้ผู้เรียนตั้งกลุ่ม พูดคุย หรือหาเพื่อนร่วมทีมทำโครงงาน
* **Could have:** 
  * ระบบคลังแบ่งปันชีทสรุปและรีวิวรายวิชา (Study Notes & Course Reviews)
* **Won't have (this term):** 
  * ระบบตลาดนัดมือสองและแลกเปลี่ยนหอพัก (Marketplace & Housing matching)

## Risks & assumptions
* **Assumptions ที่ต้อง Validate:**
  * นักศึกษายินดีที่จะย้าย/เข้ามาใช้งานแพลตฟอร์มใหม่ แทนการใช้กลุ่ม Facebook หรือ LINE OpenChat เดิม
  * ชมรมและสโมสรนักศึกษายินดีจะมาลงประกาศกิจกรรมบนแพลตฟอร์ม CampusLink เป็นช่องทางหลัก
* **ความเสี่ยงที่อาจเจอ (Risks):**
  * **Network Effect Failure:** ในช่วงแรกหากมีผู้ใช้น้อย ข่าวสารหรือกิจกรรมอาจไม่ครอบคลุม ทำให้ผู้ใช้เลิกใช้งาน (แก้ไขโดยจับมือกับสโมสรนักศึกษาเพื่อป้อนข้อมูลตั้งแต่วันแรก)
  * **Content Moderation:** ความเสี่ยงจากการโพสต์เนื้อหาที่ไม่เหมาะสม หรือการกลั่นแกล้งกันในระบบชุมชน (แก้ไขโดยใช้ระบบยืนยันตัวตนด้วยอีเมลมหาวิทยาลัยและมีระบบ Report เนื้อหา)
